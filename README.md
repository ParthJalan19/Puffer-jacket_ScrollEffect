# Puffer-jacket_ScrollEffect

An avant-garde, luxury 3D e-commerce experience for technical apparel featuring buttery smooth 60 FPS scroll-driven carousel animations, reactive studio lighting, and rich glassmorphic micro-interactions.

---

## ✨ Features

- **3D Jacket Carousel Scrub**: 238-frame scroll-driven canvas animation rotating through 5 colorways with zero blur, calibrated to a 0.58 editorial scale factor.
- **Dynamic Reactive Studio Lighting**: Studio background tones, ambient spotlights, and CSS variables dynamically adapt to each jacket colorway (*Terracotta Ochre*, *Arctic Platinum*, *Alpine Sage*, *Midnight Navy*, and *Stealth Onyx*).
- **Luxury Glassmorphism UI**: High-refraction frosted glass cards (`backdrop-filter: blur(28px)`), illuminated stat numbers, and hover tilt effects.
- **Micro-Interactions & Audio**: Web Audio API sound effects (subtle clicks, bag additions, whooshes) with persistent sound toggle.
- **Interactive Slide-Out Bag & Checkout**: Real-time cart drawer with size & colorway synchronization, order summary, and checkout celebration confetti.
- **Fit Finder & Size Guide Modal**: High-fashion measurement breakdown modal with tailored recommendations.
- **Editorial Lookbook**: Interactive 6-look fashion gallery with category filters (*Streetwear*, *Expedition*, *Atelier*) and full lightbox inspection.
- **Smooth Inertia Scrolling**: Powered by Lenis and GSAP ScrollTrigger.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ParthJalan19/Puffer-jacket_ScrollEffect.git

# Enter the directory
cd Puffer-jacket_ScrollEffect

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

## 🛠️ Tech Stack

- **Vite** — Fast, modern frontend tooling
- **GSAP & ScrollTrigger** — Kinetic scroll sequencing and scrub timelines
- **Lenis** — Hardware-accelerated smooth scrolling
- **Canvas-Confetti** — Celebration particle effects
- **HTML5 Canvas 2D** — Multi-threaded 60 FPS image sequence player with DPR scaling
- **Vanilla CSS3** — Glassmorphism, dynamic CSS custom properties, and responsive layout
